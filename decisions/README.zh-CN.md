# 决定台账

简体中文 | [English](README.md)

台账记录决定了什么、谁在什么授权范围内决定、理由和有效期，但不能代替相应控制者的确认。

状态：`proposal`、`ratified`、`implemented`、`paused`、`reversed`、`expired`、`superseded`。

每项记录包含范围、证据、替代方案、理由、决定者或确认者、回避、反对意见、负责人、期限、回滚和复审或失效日。保密决定只发布安全的去标识元数据。

请从 [`D-0000-template.zh-CN.md`](D-0000-template.zh-CN.md) 创建记录。编号单调递增，禁止静默改写历史；需要变更时用新记录取代旧记录。
