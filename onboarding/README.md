# Get Started

[Chinese](README.zh-CN.md) | English

You can participate without joining the GitHub organization.

## Your first 15 minutes

1. Read the community [README](../README.md), [Governance](../GOVERNANCE.md), and [Code of Conduct](../CODE_OF_CONDUCT.md).
2. Browse the [project map](../projects/README.md) and GitHub Discussions.
3. Choose one route: ask a question, show a project, report compatibility, improve docs, or claim an issue.
4. For defined work, comment `/claim`; claims normally last seven days and can be extended with an update.
5. Ask the responsible project maintainer for scope-specific help.

## Good first contributions

- correct or translate one page;
- reproduce a public compatibility issue without sharing sensitive data;
- improve a project description or ownership record;
- add acceptance criteria to an open task;
- summarize an upstream breaking change;
- help answer a newcomer question.

## What not to post publicly

Vulnerabilities, conduct-case identities, credentials, personal data, recovery details, and unpublished incident information belong in the private routes described by [Security](../SECURITY.md) and the [Code of Conduct](../CODE_OF_CONDUCT.md).

Organization membership and repository access are not prerequisites or rewards for a single contribution. Access follows sustained responsibility and least privilege.
