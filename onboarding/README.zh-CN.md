# 开始参与

简体中文 | [English](README.md)

参与社区不要求先加入 GitHub Organization。

## 最初15分钟

1. 阅读社区[首页](../README.zh-CN.md)、[治理规则](../GOVERNANCE.zh-CN.md)和[行为准则](../CODE_OF_CONDUCT.zh-CN.md)。
2. 浏览[项目地图](../projects/README.zh-CN.md)和 GitHub Discussions。
3. 选择一个入口：提问、展示项目、报告兼容问题、完善文档或认领 Issue。
4. 对明确任务评论 `/claim`；认领通常保留7天，发布进展可以续期。
5. 向对应项目维护者寻求具体帮助。

## 适合第一次参与的贡献

- 修正文档或翻译一页；
- 在不泄露敏感信息的前提下复现兼容问题；
- 完善项目说明或负责人记录；
- 给开放任务补充完成标准；
- 总结一次上游 breaking change；
- 帮助回答新人问题。

## 不应公开提交的内容

漏洞、CoC 当事人身份、凭据、个人数据、恢复细节和未公开事件信息，应使用[安全政策](../SECURITY.zh-CN.md)和[行为准则](../CODE_OF_CONDUCT.zh-CN.md)中的保密渠道。

组织成员和仓库权限不是参与前提，也不是一次贡献的奖励。权限跟随持续责任，并遵循最小权限原则。
