# omdsh-dev Community

> DeepSeek 相关社区插件的公开交流、收录申请与贡献者协作入口。  
> The public hub for DeepSeek-related community plugins, submissions, and contributor collaboration.

## 中文

### 欢迎参与

`omdsh-dev` 是社区自建、非官方的插件收录组织，与 DeepSeek 官方不存在隶属、授权、合作、赞助或背书关系。

任何人都可以通过公开仓库、Issue、Pull Request 和 Discussions 参与，无需先成为组织成员。我们欢迎：

- DeepSeek 相关插件的作者与维护者；
- 希望提交插件收录申请的开发者；
- 愿意参与文档、测试、兼容性验证和社区维护的贡献者；
- 对插件生态有建议、问题或反馈的使用者。

### 如何参与

- **提交插件**：在 Discussions 的 **Show and tell** 分类发帖，标题以 `[Plugin]` 开头。
- **申请参与维护**：在 **General** 分类发帖，标题以 `[Join]` 开头，并说明希望参与的方向。
- **提出建议**：使用 **Ideas** 分类。
- **提问与求助**：使用 **Q&A** 分类；插件自身的问题请优先前往相应插件仓库。
- **贡献代码或文档**：直接在相应公开仓库提交 Issue 或 Pull Request。

插件收录申请请至少包含：

1. 插件名称和仓库地址；
2. 功能简介及与 DeepSeek 的关系；
3. 安装或使用方式；
4. 开源许可证和版权归属；
5. 当前维护状态及主要维护者；
6. 已知风险、限制或兼容性说明。

### 组织成员与权限

公开参与不等于正式组织成员身份。正式成员将根据持续贡献、插件维护责任和组织协作需要，由组织所有者邀请加入。

加入组织不代表自动获得任何私有仓库权限。私有仓库仅向确有工作需要的维护者按最小权限原则开放；不同团队和仓库的权限相互独立。成员可以自行选择是否将其组织成员身份公开展示。

### 权利与免责声明

“DeepSeek”名称、商标、品牌标识、官方模型和官方材料的相关权利归 DeepSeek 官方或相应权利人所有。各社区插件的源代码、文档、设计及其他原创内容，其著作权和其他知识产权归相应插件开发者或权利人所有，并以各插件仓库中的许可证和权利声明为准。

插件被收录不代表 DeepSeek 官方或本组织对其作出授权、认证、推荐或背书，也不构成对其安全性、可用性、兼容性或持续维护的保证。

## English

### Welcome

`omdsh-dev` is an unofficial, community-run plugin catalog. It is not affiliated with, authorized by, partnered with, sponsored by, or endorsed by DeepSeek.

Anyone may participate through public repositories, issues, pull requests, and Discussions without first becoming an organization member. We welcome:

- Authors and maintainers of DeepSeek-related plugins;
- Developers who want to submit a plugin for listing;
- Contributors interested in documentation, testing, compatibility work, or community maintenance;
- Users with ideas, questions, or feedback about the plugin ecosystem.

### How to Participate

- **Submit a plugin:** Start a Discussion in **Show and tell** with a title beginning with `[Plugin]`.
- **Help maintain the community:** Start a Discussion in **General** with a title beginning with `[Join]` and describe how you would like to contribute.
- **Propose an idea:** Use **Ideas**.
- **Ask for help:** Use **Q&A**. For plugin-specific problems, please use the plugin's own repository first.
- **Contribute code or documentation:** Open an issue or pull request in the relevant public repository.

A plugin submission should include at least:

1. Plugin name and repository URL;
2. A short description and its relationship to DeepSeek;
3. Installation or usage instructions;
4. Open-source license and copyright ownership;
5. Current maintenance status and primary maintainers;
6. Known risks, limitations, or compatibility notes.

### Membership and Access

Public participation does not automatically confer organization membership. Formal membership is invitation-based and is considered according to sustained contributions, plugin maintenance responsibilities, and collaboration needs.

Organization membership does not automatically grant access to private repositories. Private access is granted only where needed, following least-privilege principles; repository and team permissions remain separate. Members may choose whether to display their organization membership publicly.
