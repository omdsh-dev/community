# omdsh-dev Community

[简体中文](README.zh-CN.md) | English

`omdsh-dev` is the public collaboration hub around [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): plugins, tools, distributions, compatibility work, shared practices, and community proposals.

We are unofficial and independent. We are not affiliated with, authorized by, partnered with, sponsored by, or endorsed by DeepSeek.

## How we work

- **Community coordination, project autonomy.** Shared processes live here; technical decisions stay with each project's maintainers.
- **Multiple catalogs and markets may coexist.** The community does not designate a single official marketplace.
- **Listing is not endorsement.** Discovery, source verification, community review, and runtime risk are separate signals.
- **Authority follows the asset.** A meeting or repository cannot create authority over another organization, project, account, or brand.
- **Lightweight by default.** Reversible routine work moves quickly; security, root assets, conduct cases, and other high-impact matters receive additional process.

Read [Governance](GOVERNANCE.md), [Contributing](CONTRIBUTING.md), [Code of Conduct](CODE_OF_CONDUCT.md), and [Security](SECURITY.md).

## Participate

- Show a plugin or project: start a **Show and tell** Discussion with `[Plugin]` or `[Project]`.
- Propose an idea or ask for help: use **Ideas** or **Q&A**.
- Propose a community decision: use the Community Proposal issue form.
- Report upstream breakage: use the Compatibility Report issue form.
- Contribute code or docs: open an issue or pull request in the relevant project.
- Report sensitive matters: follow [Security](SECURITY.md) or the private route in the [Code of Conduct](CODE_OF_CONDUCT.md), never a public issue.

Public participation does not require organization membership. Access is granted for a defined responsibility and follows least privilege.

## Ecosystem services

Catalogs, curated markets, source-verification services, distribution allowlists, and enterprise lists are independent projects. A service claiming conformance with an oh-my-dsh specification should disclose its operator, intake/review scope, ranking incentives, update/removal process, appeal route, and shutdown/export plan.

## Governance status

The governance files are proposed for a reversible 30-day trial. Merging them does not establish permanent offices or cross-organization authority. Binding application requires confirmation by the controller of each affected asset.
