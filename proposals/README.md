# Proposals

[Chinese](README.zh-CN.md) | English

Use proposals for cross-project coordination or changes to community process. Ordinary project work stays in the project's own issue/PR flow.

Statuses: `draft → discussion → awaiting-ratification → accepted/rejected → implemented → superseded/expired`.

1. Start with the Community Proposal issue form.
2. Identify affected assets and who can ratify each one.
3. Link evidence, alternatives, affected groups, conflicts, reversibility, owner, and review date.
4. Keep sensitive material out of the public proposal.
5. Accepted proposals create a decision record in [`../decisions`](../decisions/README.md).

Copy [`P-0000-template.md`](P-0000-template.md) for a substantial written proposal. A proposal does not become binding through popularity or meeting attendance alone.
