# 社区提案

简体中文 | [English](README.md)

跨项目协调或社区流程变更使用提案；普通项目工作保留在项目自己的 Issue/PR 流程中。

状态：`draft → discussion → awaiting-ratification → accepted/rejected → implemented → superseded/expired`。

1. 从 Community Proposal Issue 表单开始。
2. 识别涉及资产，以及谁能确认每项资产。
3. 链接证据、替代方案、受影响群体、利益冲突、可逆性、负责人和复审日。
4. 敏感材料不得进入公开提案。
5. 被接受的提案在 [`../decisions`](../decisions/README.zh-CN.md) 建立决定记录。

重要书面提案请复制 [`P-0000-template.zh-CN.md`](P-0000-template.zh-CN.md)。提案不会仅因热度或会议出席而自动产生约束力。
