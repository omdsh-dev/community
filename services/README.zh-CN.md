# 生态服务

简体中文 | [English](README.md)

生态可以同时存在宽发现目录、精选市场、来源验证 feed、发行版 allowlist 和企业私有列表。这些服务是独立项目，不是某一个官方市场的下属分支。

符合社区规范意味着声明透明，不意味着安全保证。服务应公开运营与控制者、目的、收录来源、审阅范围和未覆盖范围、排序或赞助激励、版本和制品模型、运行风险信号、更新和维护权转移处理、暂停/下架/通知、申诉、数据隐私以及停运导出方案。
