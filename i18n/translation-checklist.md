# Translation review checklist

- [ ] Separate `.zh-CN.md` file; no duplicated bilingual body.
- [ ] Language switch links work in both directions.
- [ ] Headings, tables, links, examples, and status values are present.
- [ ] Authority, scope, deadlines, exceptions, privacy, enforcement, rollback, and expiry have the same meaning.
- [ ] No new promise, endorsement, legal conclusion, or security guarantee was introduced.
- [ ] Product names, code identifiers, and normative words remain precise.
- [ ] Material machine or AI assistance is disclosed and human-reviewed.
- [ ] Local Markdown links and YAML parse successfully.
