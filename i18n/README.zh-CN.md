# 国际化与翻译

简体中文 | [English](README.md)

英文是默认文档语言。简体中文使用独立的 `.zh-CN.md` 文件，不在同一文档中放置完整的中英文正文。

## 文件约定

- `README.md` → 默认英文
- `README.zh-CN.md` → 简体中文
- `template.md` → 默认英文模板
- `template.zh-CN.md` → 简体中文模板
- Issue 表单使用独立英文文件和 `-zh-CN.yml` 文件。

文档顶部可以保留语言切换链接。代码标识、角色名称、状态和产品名在翻译会降低准确性时可以保留英文。

## 变更流程

1. 治理、安全、CoC 和权限等高影响变更必须在同一个 PR 更新两种语言。
2. 普通文档可以先合并，但必须关联翻译任务，并明确标记暂时不同步。
3. 复核重点包括授权、期限、例外、隐私和执行措施的语义一致性。
4. 两个版本存在实质分歧时，暂停相关决定，直至协调完成；试点期间任何版本都不会静默覆盖另一版本。
5. 机器或 AI 生成的翻译必须由愿意对含义和许可证负责的贡献者审阅。

复核时使用 [`translation-checklist.zh-CN.md`](translation-checklist.zh-CN.md)。
