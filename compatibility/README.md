# Upstream Compatibility

[Chinese](README.zh-CN.md) | English

This area coordinates DeepSeek Harness changes across autonomous projects. It does not guarantee compatibility for every project.

Statuses: `supported`, `degraded`, `paused`, `unknown`.

When a breaking change is confirmed:

1. open a Compatibility Report with the upstream version/commit and evidence;
2. identify affected projects and versions;
3. each project maintainer confirms its own status;
4. record workaround, owner, next update, and recovery criteria;
5. publish a shared summary and send common upstream feedback where appropriate;
6. close only when affected projects are fixed, intentionally paused, or explicitly unknown.

Use [`status-template.md`](status-template.md). Never publish an uncoordinated vulnerability through this process.
