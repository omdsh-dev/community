# 上游兼容协作

简体中文 | [English](README.md)

本目录协调 DeepSeek Harness 变化对自治项目的影响，不保证所有项目始终兼容。

状态：`supported`、`degraded`、`paused`、`unknown`。

确认 breaking change 后：

1. 用 Compatibility Report 提交上游版本或 commit 和证据；
2. 识别受影响项目和版本；
3. 各项目维护者确认自己的状态；
4. 记录临时方案、负责人、下次更新和恢复标准；
5. 发布共同摘要，并在适合时向上游反馈共性问题；
6. 只有在项目修复、明确暂停或明确未知后关闭。

请使用 [`status-template.zh-CN.md`](status-template.zh-CN.md)。不得通过此流程公开未协调披露的漏洞。
