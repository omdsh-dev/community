# Working Groups

[Chinese](README.zh-CN.md) | English

Working groups are temporary, task-focused coordination units. They do not own permanent assets or create a new authority layer.

A group needs a concrete outcome, facilitator, participating projects, public task list, meeting/async route, success measure, expiry date (normally 30–60 days), and archive plan. It closes automatically at expiry unless renewed with evidence of need.

Likely early groups include upstream compatibility, newcomer experience, and community operations. Security or conduct response is not a public working group and follows restricted case handling.

Use [`charter-template.md`](charter-template.md). A group cannot grant repository access; the relevant controller must do so separately.
