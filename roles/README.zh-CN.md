# 角色与责任

简体中文 | [English](README.md)

角色描述工作，不代表身份高低。权限只覆盖实际承担责任的仓库或资产。

| 角色 | 常见证据 | 权限范围 | 复审 |
|---|---|---|---|
| Participant | 提问、反馈、参会 | 公开参与 | 无 |
| Contributor | 被接受的贡献 | 普通贡献权限 | 持续 |
| Triager | 持续帮助 Issue/Discussion | 指定仓库 Triage | 试点期90天 |
| Repository Maintainer | 持续技术负责 | 仅指定仓库 | 试点期90天 |
| Steward | 社区流程和记录 | 明确的社区文件/流程 | 30天试点 |
| Compatibility Coordinator | 上游变化协调 | 默认只管理兼容记录 | 30天试点 |
| Security/Conduct Contact | 受信任的敏感受理 | 案件最小知情范围 | 逐案和30天试点 |
| Emeritus | 原活跃责任人 | 默认无敏感权限 | 按需 |

试点期晋升需要公开证据、一名无冲突担保人、明确范围、最小权限和复审日。请使用 [`role-template.zh-CN.md`](role-template.zh-CN.md)。敏感案件复核者不得是原决定者。
