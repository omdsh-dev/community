# omdsh-dev 社区

简体中文 | [English](README.md)

`omdsh-dev` 是围绕 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 建立的公共协作入口，服务于插件、工具、发行方案、兼容协作、共同实践和社区提案。

本社区是非官方、独立的社区项目，与 DeepSeek 不存在隶属、授权、合作、赞助或背书关系。

## 社区如何运作

- **社区协调，项目自治。** 共同流程放在这里，各项目的技术决定由其维护者负责。
- **多个目录和市场并存。** 社区不指定唯一官方插件市场。
- **收录不等于背书。** 发现、来源验证、社区审阅和运行风险是不同信号。
- **权限跟随资产。** 一次会议或一个仓库不能自动获得对其他组织、项目、账号或品牌的决定权。
- **默认轻量。** 可逆的日常工作快速推进；安全、根资产和行为准则等高影响事项采用更严格程序。

请阅读[治理规则](GOVERNANCE.zh-CN.md)、[贡献指南](CONTRIBUTING.zh-CN.md)、[行为准则](CODE_OF_CONDUCT.zh-CN.md)和[安全政策](SECURITY.zh-CN.md)。

## 如何参与

- 展示插件或项目：在 **Show and tell** Discussion 发帖，标题以 `[Plugin]` 或 `[Project]` 开头。
- 提出想法或求助：使用 **Ideas** 或 **Q&A**。
- 提出社区决定：使用 Community Proposal Issue 表单。
- 报告上游兼容问题：使用 Compatibility Report Issue 表单。
- 贡献代码或文档：在对应项目提交 Issue 或 Pull Request。
- 报告敏感事项：遵循[安全政策](SECURITY.zh-CN.md)或[行为准则](CODE_OF_CONDUCT.zh-CN.md)中的保密渠道，禁止公开提交。

公开参与不要求先加入 GitHub Organization。权限只因明确责任授予，并遵循最小权限原则。

## 生态服务

发现目录、精选市场、来源验证服务、发行版 allowlist 和企业列表都是独立项目。声称符合 oh-my-dsh 社区规范的服务，应公开运营者、收录与审阅范围、排序激励、更新与下架流程、申诉入口和停运导出方案。

## 治理状态

本仓库的治理文件建议先进行可撤回的30天试点。文件被合并不等于建立永久职位或跨组织授权；规则要约束某项资产，仍须由该资产的实际控制者确认。
